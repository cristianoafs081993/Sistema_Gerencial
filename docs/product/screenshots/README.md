# Pasta de Capturas de Tela (Screenshots)

Coloque aqui as capturas de tela do sistema **GovAnalytics** para que elas apareçam automaticamente na apresentação gerencial [apresentacao_sistema.html](../apresentacao_sistema.html).

## Nomes e formatos recomendados:

1. **`tela_problema.png`**: Print do dashboard inicial com dados orçamentários.
2. **`tela_solucao.png`**: Print de saldos consolidados e limites orçamentários.
3. **`tela_empenhos.png`**: Print da aba de empenhos ou controle de descentralizações.
4. **`tela_suap.png`**: Print da integração do SUAP / metas planejadas.
5. **`tela_ia.png`**: Print do assistente gerencial IA.
6. **`tela_expansao.png`**: Print das configurações de unidades ou visão multi-campus.

*Os arquivos devem estar no formato PNG para corresponderem exatamente aos links no arquivo HTML.*
